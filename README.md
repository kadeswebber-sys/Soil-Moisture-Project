# Soil-Moisture-Project
This is my desgin to make a plant watering system based off of the input of a soil moisture sensor attatched with an arduino nano and a DC motor which I use to make a centrifugal pump. 
BOM for electrical components:
1. Arduino (really any will do, I started witha a larger one and then switched over to an arduino nano)
2. DC Motor
3. Flyback Diode
4. 220 Ω Resistor
5. Transistor
6. Soil Moisture sensor
BOM for pump:
1. Tube ( I used one thats about 3 feet)
2. 3 bottle caps
